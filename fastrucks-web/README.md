# Fastrucks Platform (Web & Admin Portal)

A comprehensive Web and Mobile application platform for connecting large vehicle transporters and cargo suppliers in Kenya.

## Features
- **Supplier Portal**: Post freight jobs across domestic Kenyan and regional cross-border corridors (Northern Corridor to Uganda/Rwanda, Central Corridor to Tanzania, LAPSSET Corridor to Ethiopia, South Sudan Corridor).
- **Transporter Portal**: Driver profile with statutory vetting compliance (Kenya Traffic Act CAP 403, Age ≥ 28), available load board, bidding and price proposals, stoppage & rest/meal break logger (for fatigue management & weighbridge delays), and digital Proof of Delivery (e-POD) with secret 4-digit PIN verification.
- **System Administrator Portal**: Government statutory database verification engine (NTSA TIMS & eCitizen / IPRS lookup for Class BCE licenses and logbook chassis matching), user directory management, and cargo claims mediation docket.
- **50/50 Milestone Payment Workflow**: 50% fuel & mobilization advance released upon physical warehouse loading verification, and remaining 50% final settlement released upon verified e-POD sign-off.
- **Safaricom M-Pesa Daraja Integration**: Escrow deposits, B2C fuel disbursements, and final settlements with transaction ledger.

## Quick Start
```bash
npm install
npm run dev
```
Open http://localhost:3000 to launch the application.
